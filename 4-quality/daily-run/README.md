# Щоденний прогін

Скрипт [daily_run.py](daily_run.py) щоранку протягом робочого тижня перевіряє, як сайт реагує на справжні запити до моделі ШІ (кейси TC-55…TC-57, [test-plan.md](../test-plan.md), розділ 9).

1. Запустити бекенд з робочими налаштуваннями:

   ```bash
   cd backend
   uvicorn app.main:app
   ```

2. В іншому терміналі (потрібен лише Python 3.10+, без бібліотек):

   ```bash
   python 4-quality/daily-run/daily_run.py --per-style 3 --users 5
   ```

   `--url http://IP:8000` — якщо бекенд на іншому компʼютері.

3. Скрипт друкує таблицю (стиль, код відповіді, час, початок тексту) і дописує зведення дня в `results.jsonl`. Перенести цифри в рядок дня в [test-report.md](../test-report.md), розділ 4.

Один прогін — 14 генерацій, тобто частина безкоштовного добового ліміту Gemini; не запускати кілька разів поспіль.
