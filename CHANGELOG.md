## [0.1.0] - 2026-10-19

### Додано

- MVP: форма з імʼям (FR-01), три стилі гумору — «Брейнрот», «Душевно», «Офіційно» (FR-02), генерація привітання (FR-03), повідомлення про помилку з «Повторити» (FR-06), стан «Генеруємо…» (FR-10).
- Бекенд FastAPI: `POST /api/greetings`, `GET /api/health`, CORS, ліміт одночасних викликів LLM із відповіддю 429, 503 при недоступності LLM.
- LLM-провайдери за спільним інтерфейсом: Gemini (за замовчуванням, безкоштовний тариф), Claude, заглушка `mock`.
- Фронтенд React + Vite, адаптивний від 360 px, світла й темна теми.
- Docker-образи бекенду й фронтенду (nginx), `docker-compose.yml`.
- CI у GitHub Actions: Ruff, ESLint, pytest (28 тестів), Vitest (5 тестів), збирання образів; перевірка Markdown і посилань.
- Системні тести в браузері (Playwright + Edge) і скриншоти прототипу.
- Документація за темами курсу ТСПП: `0-product` … `5-management`.

### Змінено

- LLM-провайдер за замовчуванням: Claude API → безкоштовний Gemini API (CR-01).

### Виправлено

- Імʼя з одних пробілів більше не проходить валідацію (BUG-01).
- На вичерпаний ліміт провайдера — повідомлення «спробуйте за хвилину» замість «зачекайте кілька секунд» (BUG-02).
- У лог потрапляють токени «обдумування» Gemini (BUG-08).

### Відомі проблеми

- Генерація на `gemini-3.8-flash` іноді триває понад 10 с або завершується 504 (BUG-03).
