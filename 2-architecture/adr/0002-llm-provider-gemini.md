# ADR-0002. LLM-провайдер: безкоштовний тариф Gemini за інтерфейсом-адаптером

- **Статус:** прийнято (замінює початковий вибір Claude API); ⚠️ вибір моделі переглядається в ітерації 2 через BUG-03
- **Дата:** 19.10.2026
- **Учасники:** Б (архітектор), А (PO)

## Контекст

Початково бекенд викликав Claude API (`claude-opus-5-5`). Claude API працює лише за передоплатою, а бюджет команди на API — $0 ([CR-01](../../1-lifecycle/changes.md)). Вимоги: хороша українська, час відповіді ≤ 10 с (NFR-1), без витрат (NFR-2), можливість змінити провайдера (NFR-9).

## Варіанти

| Варіант | Ціна | Українська | Час | Мінуси |
|---|---|---|---|---|
| Claude API | платно (передоплата) | дуже добре | — | бюджет $0 |
| **Gemini API, `gemini-3.8-flash`** | безкоштовний тариф | добре, правильний кличний відмінок | медіана 4,9 с, бувають 9–14 с і 504 | на безкоштовному тарифі запити можуть іти на навчання моделей |
| Gemini API, `gemini-3.5-flash-lite` | безкоштовний тариф | прийнятно, бувають граматичні помилки («Шановний Саше») | медіана 1,1 с, максимум 3,7 с | якість гумору нижча |
| Локальна модель (Ollama) | безкоштовно | слабко на малих моделях | залежить від заліза | потрібен сервер із GPU |

Час — заміри 19.10.2026, по 5 викликів на модель ([test-report.md](../../4-quality/test-report.md)).

## Рішення

1. Провайдер за замовчуванням — **Gemini API на безкоштовному тарифі**, модель `gemini-3.8-flash`, рівень «обдумування» `low`.
2. Провайдер схований за інтерфейсом `GreetingGenerator` (`backend/app/llm.py`) з реалізаціями `GeminiGenerator`, `ClaudeGenerator`, `MockGenerator`; вибір — змінною `LLM_PROVIDER`, модель — `LLM_MODEL`.
3. У запит до Gemini передаємо лише імʼя й параметри, без інших персональних даних.

## Наслідки

- ➕ $0 на API; заміна провайдера чи моделі — одна змінна `.env` (NFR-9 підтверджено на практиці).
- ➕ Заглушка `mock` дає тести й навантажувальний тест без мережі.
- ➖ **NFR-1 не виконується на `gemini-3.8-flash`** (BUG-03). Варіанти розвʼязання в ітерації 2: перейти на `gemini-3.5-flash-lite` або додати стрімінг SSE.
- ➖ Ліміти безкоштовного тарифу (запити на хвилину й на добу) обмежують стрес-сценарій; при 429 користувач бачить «спробуйте за хвилину».
- ➖ Умови безкоштовного тарифу дозволяють Google використовувати запити — зафіксовано в [privacy.md](../../5-management/privacy.md).
