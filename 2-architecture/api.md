## Помилки (спільні для всіх операцій)

| Код | Коли | Тіло | Що показує фронтенд |
|---|---|---|---|
| 422 | невалідний запит | `{"detail": [{"loc": [...], "msg": "...", "type": "..."}]}` (формат FastAPI) | «Не вдалося згенерувати привітання» (BUG-05: має бути конкретне повідомлення) |
| 429 | зайняті всі слоти виклику LLM | `{"detail": "Забагато запитів, зачекайте кілька секунд"}` | текст `detail` + «Повторити» |
| 429 | вичерпано ліміт провайдера | `{"detail": "Сервіс генерації зараз перевантажений, спробуйте за хвилину"}` | текст `detail` + «Повторити» |
| 503 | LLM недоступний, таймаут, відповідь заблоковано | `{"detail": "Сервіс генерації тимчасово недоступний"}` | текст `detail` + «Повторити» |
| 404 | ресурс не знайдено (операції 5, 7) | `{"detail": "Не знайдено"}` | «Привітання не знайдено» |

## 1. `GET /api/health`

Відповідь `200`:

```json
{"status": "ok"}
```

Використовується в healthcheck Docker і після розгортання в CI.

## 2. `POST /api/greetings`

### Параметри тіла

| Поле | Тип | Обовʼязкове | Правила | Приклад |
|---|---|---|---|---|
| `name` | string | так | пробіли по краях обрізаються; після цього 1–50 символів | `"Саша"` |
| `style` | string | так | `brainrot` \| `warm` \| `official` | `"brainrot"` |
| `interests` | string[] | ні (v0.2) | 0–3 значення з `GET /api/interests` | `["games", "anime"]` |

Повні правила — у [validation-rules.md](../3-implementation/validation-rules.md).

### Запит

```http
POST /api/greetings
Content-Type: application/json

{"name": "Саша", "style": "brainrot"}
```

### Відповідь `200` — реальний приклад із прогону 19.10.2026

```json
{
  "text": "Йоу, Саша, з днем народження, твій рівень скібіді-різзу сьогодні просто пробив стелю! 🗿 Бажаю тобі нескінченної аури +1000000…",
  "style": "brainrot"
}
```

З v0.3 відповідь отримає поле `id` (UUID) для операції 5 — це сумісне розширення (мінорна версія 0.3.0).

### Помилка `422` — порожнє імʼя

```json
{"detail": [{"type": "string_too_short", "loc": ["body", "name"], "msg": "String should have at least 1 character", "input": "", "ctx": {"min_length": 1}}]}
```

Перегенерація (FR-04) — це повторний виклик із тими самими параметрами.

## 5. `POST /api/greetings/{id}/rating` — v0.3

### Запит

```json
{"value": "up"}
```

`value`: `up` \| `down`. Повторний виклик замінює оцінку.

**Відповідь `204`** без тіла. **`404`**, якщо привітання з таким `id` немає.

## 6. `POST /api/cards` — Won't

**Запит:** `{"greeting_id": "3f2b…"}` → **Відповідь `201`:** `{"slug": "k7Pq2x", "url": "/c/k7Pq2x", "expires_at": "2026-11-19T00:00:00Z"}`

## 7. `GET /api/cards/{slug}` — Won't

**Відповідь `200`:** `{"text": "…", "style": "warm", "created_at": "2026-10-19T20:41:00Z"}`; **`404`**, якщо листівку видалено або термін минув.

## Сумісність і версіонування

- Додавання необовʼязкових полів і нових операцій — мінорна версія (0.1 → 0.2).
- Видалення або перейменування полів, зміна кодів помилок — мажорна версія; тоді додаємо префікс `/api/v2` і тримаємо `/api` до наступного релізу (зауваження RV-08 у [review-report.md](../4-quality/review-report.md)).
