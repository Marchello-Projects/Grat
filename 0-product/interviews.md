# Інтервʼю

> **Статус: план, інтервʼю ще не проведено.** Заповніть таблицю конспектів після 5+ розмов із людьми поза командою. Висновки використайте для [personas.md](personas.md) і пріоритетів у [mvp.md](../1-lifecycle/mvp.md).

## Мета

Перевірити гіпотези:

1. Люди витрачають на привітання помітний час (≥ 5 хв) і хотіли б швидше.
2. Готові шаблони не влаштовують, бо «не про людину».
3. Брейнрот-гумор доречний для друзів, офіційний стиль — для колективу.
4. Людина надішле згенерований текст без редагування, якщо він смішний і без образ.

## Питання (без підказок відповіді)

1. Розкажіть про останній раз, коли ви вітали когось із днем народження. Як це було?
2. Скільки часу це зайняло? Що було найважче?
3. Звідки берете ідеї для привітань?
4. Чи бувало, що жарт у привітанні сприйняли не так? Що сталося?
5. Чи користуєтесь ChatGPT або подібними для текстів? Для привітань пробували? Що не сподобалось?
6. Покажіть, як би ви привітали друга прямо зараз (спостерігаємо, не підказуємо).
7. Що мало б бути в ідеальному привітанні для вас?
