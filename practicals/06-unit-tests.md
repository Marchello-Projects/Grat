## 1. Вибір місця за ціною помилки

Три ризиковані місця — з домашнього практичної 5. На кожного — своє:

| Хто | Місце | Що станеться з користувачем | Коли помітять | Шляхів |
|---|---|---|---|---|
| **Аліна** | `names.check` — фільтр «команд» у полі імені | пропущена команда → образливе привітання переслане імениннику (NFR-5) | **не помітять узагалі**, поки іменинник не образиться: фільтр мовчки пропускає | 6: перенос рядка, порожньо, > 50, заборонений символ, > 3 слів, ок |
| **Макс** | `quality.review` — пошук імені й підрахунок речень | хибне «все добре» пропускає брак у звіти тестувальника; хибне «немає імені» вчить ігнорувати зауваження | через тижні — коли звіт щоденного прогону розійдеться з тим, що бачать люди | 4 перевірки × 3 стилі |
| **Марк** | `FallbackGenerator` — ланцюжок резерву | збій → знову 0 привітань (BUG-10) | одразу — але лише якщо хтось дивиться в лог | 3: відповів, пропустити далі, усі впали |

**Чим пізніше помітять, тим раніше тестуємо:** першими — `names` і `quality`, бо вони помиляються тихо. Резерв падає голосно, тому він третій.

## 3. Тести в коді: один — червоним першим (TDD)

Кожен тест — три частини: дано, дія, перевірка; одна причина падіння.

```python
def test_unexpected_error_in_link_falls_back_too():
    gen = FallbackGenerator([("main", Fake(error=RuntimeError("boom"))), ("t", Fake("шаблон"))])  # дано
    text = asyncio.run(gen.generate("Саша", Style.warm))                                          # дія
    assert text == "шаблон"                                                                        # перевірка
```

### Як це лягає в git (кожен від свого імені)

Два коміти на дефект — тест окремо, правка окремо, щоб в історії було видно червоне перед зеленим:

```bash
# Аліна
git switch -c fix/bug-12-backtick-apostrophe
git add backend/tests/test_names.py && git commit -m "test: апостроф із клавіші \` не відхиляється (BUG-12)"
git add backend/app/names.py        && git commit -m "fix: names приймає апостроф із клавіші \` (BUG-12)"

# Макс
git switch -c fix/bug-13-typographic-apostrophe
git add backend/tests/test_quality.py && git commit -m "test: імʼя з типографським апострофом знаходиться (BUG-13)"
git add backend/app/quality.py        && git commit -m "fix: quality зводить апострофи до одного (BUG-13)"

# Марк
git switch -c fix/bug-14-fallbacks-comma
git add backend/tests/test_fallback.py && git commit -m "test: зайва кома в LLM_FALLBACKS не валить сервер (BUG-14)"
git add backend/app/llm.py             && git commit -m "fix: make_generator пропускає порожні ланки резерву (BUG-14)"
```

Так само окремими комітами — свій TDD-тест і правка до нього. Squash merge при злитті PR лишить у `main` один коміт на задачу, тож червоне перед зеленим видно в історії гілки й у PR.
